# 🎮 QUICK START - Play the Game NOW!

## 🦖 Dino Runner Game (Main Game)

### 3 Simple Steps:

1. **Open** → Help → About
2. **Scroll** → Find "Fun Stats" section
3. **Click** → Big rainbow "PLAY DINO RUNNER" button

### Controls:
- **SPACE** = Jump
- **R** = Restart

### Goal:
Avoid obstacles and get the highest score!

## 🚀 Space Shooter (Secret Game)

### Unlock Code:
Type: **↑ ↑ ↓ ↓ ← → ← → B A**

### Controls:
- **Arrows** = Move
- **SPACE** = Shoot
- **R** = Restart
