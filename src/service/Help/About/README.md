## 🎯 Quick Access:

2. **Scroll Down** to "Fun Stats" section
3. **Click** the big rainbow "PLAY DINO RUNNER" button
4. **Press SPACE** to jump!

## 🎮 Two Games Available:

### 1. 🦖 Dino Runner (Main Game)
- **Access**: Click the button (see above)
- **Style**: Chrome offline game clone
- **Controls**: SPACE to jump
- **Goal**: Avoid obstacles, get high score

### 2. 🚀 Space Shooter (Secret Game)
- **Access**: Type Konami Code (↑↑↓↓←→←→BA)
- **Style**: Retro space shooter
- **Controls**: Arrows to move, SPACE to shoot
- **Goal**: Destroy enemies, survive
